1. Расчет площади помещения

S = Ширина × Длина = 5м × 9м = 45 м²

2. Расчет кол-ва плитки без запаса

N = S / S_плитки = 45 / 1.44 ≈ 31.25 уп.

3. Добавление запаса (10%)

N_final = 31.25 × 1.1 = 34.375 → 35 уп.
// Учитывая подрезку и бой
